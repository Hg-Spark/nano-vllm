## 每次实验保留什么

- 日期、执行人、代码提交及是否有未提交改动。
- 模型来源、检查点 revision、权重 dtype 与实际加载范围。
- GPU 型号/显存、PyTorch、CUDA、Triton、Transformers、FlashInfer 版本。
- 完整命令、输入或随机种子、生成设置、并发/token/上下文限制。
- KV dtype、K/V scale、前缀缓存设置、预热与重复次数。
- 原始输出日志或 trace、失败信息、指标单位和最终结论。

仓库脚本不会自动记录上述全部信息，应手动补齐。请保存原始 token ID 和首个不一致位置，不要只截取生成文本。

## 状态约定

- **待验证（PENDING）**：没有可用测量结果。
- **通过**：所记录输入、配置和检查项已经满足判定条件，不外推到所有场景。
- **失败**：已执行但未满足判定条件，保留失败证据。
- **环境阻塞**：因容量或依赖未能完成实验，不等于数值失败。

性能对比保持模型、工作负载、设置和统计口径一致。若更换设备或权重精度，另建记录并写明差异。现有文件名不能作为实验成功的证据。
